## 🚀 Mes projets en Réseaux & Télécoms

### ☁️ Plateforme IoT et Météo (SAE_23)
Conception d'une plateforme de gestion d'informations IoT (Internet of Things) affichant des données météorologiques.
* **Fonctionnalités :** Collecte de données en temps réel via une **API météo**, communication via le protocole **MQTT** et restitution visuelle sous forme de graphiques sur une page web hébergée sur le serveur de l'IUT.
* **Technologies :** **MQTT**, **PHP**, API REST, Web.
* 🔗 [Lien vers le dépôt](https://github.com/jader01/SAE_23)
